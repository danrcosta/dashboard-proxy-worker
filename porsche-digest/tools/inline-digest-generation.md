# Daily Automation Pattern — Inline Generation

## Context
Session: 19 August 2026  
Skill: daily-digest-generator  
Profile: pessoal  

## Problem
Generating a daily digest requires either:
1. A separate generator script file (e.g. `generate_digest.py`)
2. Manual JSON editing (error-prone)
3. A full Python/Node pipeline (overkill for daily)

## Solution: Inline `node -e` Generation

For daily automation, generate `digest.json` **inline** using Node's `-e` flag:

```bash
node -e "
const fs = require('fs');
const today = new Date().toISOString().split('T')[0];
const data = { 
  meta: { 
    schema_version: '6.0',
    generated_at: new Date().toISOString(), 
    seed: false, 
    edition_date: today 
  }, 
  lead: { 
    kicker: 'Daily Digest — ' + today, 
    headline: '...', 
    standfirst: '...', 
    body: ['...'] 
  },
  market: { live: [], sold: [] },
  valuation: { models: [...] }
};
fs.writeFileSync('public/data/digest.json', JSON.stringify(data, null, 2));
console.log('✅ Digest gerado: ' + today);
"
```

### Benefits
- ✅ **No extra files** — one-liner in terminal
- ✅ **Cron-friendly** — easy to schedule
- ✅ **Reproducible** — same structure every day
- ✅ **Fast** — sub-second generation

### When to Use
- ✅ Daily digest updates
- ✅ Cron jobs (GitHub Actions, cronjob skill)
- ✅ Quick prototyping
- ❌ Complex data fetching (use Python script)
- ❌ Multi-source aggregation (use generator script)

## Git Pitfall (Critical!)

`.gitignore` marks runtime files as protected:
```
public/data/sources.json  ← ignored
```

**Symptom:**
```bash
git add public/data/digest.json
The following paths are ignored by one of your .gitignore files:
    porsche-digest/public/data/sources.json
```

**Fix:**
```bash
git add -f public/data/digest.json  # Force add
```

**Rule:** Runtime-generated files in `public/data/` are regenerated by `node tools/build.mjs` — never hand-edit them. Always force-add with `-f`.

## Command Sequence (Daily)

1. **Generate**
   ```bash
   node -e "generate digest.json"
   ```
2. **Build & Validate**
   ```bash
   node tools/build.mjs
   ```
3. **Score**
   ```bash
   node tools/score-listing.mjs public/data/digest.json
   ```
4. **Stage (force)**
   ```bash
   git add -f public/data/digest.json
   ```
5. **Commit**
   ```bash
   git commit -m "📊 Daily digest: $(date +%Y-%m-%d)" && git push
   ```
6. **Deploy**
   → GitHub → Cloudflare Pages auto-deploy
